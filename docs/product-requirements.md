# プロダクト要求定義書（product-requirements.md）

## 1. プロダクトビジョンと目的

M5Stack AtomS3 単体で完結する、タッチセンサーを使った「イライラ棒」風ミニゲームを開発する。
物理的なワイヤーではなく、AtomS3の静電容量式タッチセンサー（GPIO5〜8）を十字キーとして扱い、画面左側に配置された自機を上下左右に微調整しながら、右から迫ってくる壁（障害物）を避け続ける横スクロール型の生存ゲームとする。
壁は時間経過とともに間隔（通り抜け用の開口＝隙間、および壁同士の出現間隔＝頻度）の両方が狭くなり、難易度が上がっていく。決定・キャンセルの操作は外付けの物理スイッチ（GPIO39＝OK、GPIO38＝キャンセル）で行う。
電源ONで表示されるスタート画面から「チュートリアル」「ゲーム開始」「設定」の3項目を選択できるようにし、初めて遊ぶ人でも操作方法とルールを理解してから本編に進めるようにする。
「ゲーム開始」を選ぶと、続けて難易度（レベル1〜3）を選択する画面に進む。難易度は自機のサイズと壁が狭くなる速度を左右し、レベル1は自機が小さく壁が狭くなる速度が遅い（易しい）、レベル3は自機が大きく壁が狭くなる速度が速い（難しい）とする。

- タッチ操作による方向入力という制約（アナログ的で反応がブレやすい）を活かし、「思い通りに操作できないイライラ感」自体をゲーム性として楽しむ。
- 既存の動作確認用プログラム（`main.cpp` / `GUI.cpp`）で得られたタッチセンサーの反応（`touchRead`の値の変化）を土台に、ゲームロジックを追加する。

## 2. ターゲットユーザーと課題・ニーズ

- **想定ユーザー**: AtomS3を持っている個人開発者・電子工作愛好家（自分自身）。展示・デモや友人・同僚へのちょっとした余興としての利用も想定。
- **課題・ニーズ**:
  - タッチセンサーだけで方向入力ができる、物理ボタンを使わない小型ゲームがほしい。
  - AtomS3の小さな画面でも完結する、単純明快な操作・ルールのゲームがほしい。
  - タッチセンサーの感度差・個体差があっても遊べる調整のしやすさがほしい。
  - 時間経過とともに難易度が自然に上がっていく、繰り返し遊べるスコアアタック型のゲームがほしい。

## 3. 主要な機能一覧

1. タッチセンサー4方向入力（上下左右）による自機の微調整移動（自機は画面左側を基準位置とする）
2. 物理ボタン2つ（OK＝GPIO39、キャンセル＝GPIO38）による決定・戻る操作
3. 壁（障害物）の生成・右から出現して左へスクロールする表示
4. 壁の開口（自機が通り抜ける隙間）が時間経過とともに狭くなる難易度上昇
5. 壁同士の出現間隔（頻度）が時間経過とともに狭くなる難易度上昇
6. 壁接触判定（イライラ棒の「棒が輪に触れる」に相当。接触時点で失敗＝ゲームオーバー）
7. 生存時間の計測・表示（クリアはなく、生存時間がそのままスコアとなる）
8. ゲーム状態遷移（タイトル／プレイ中／ゲームオーバー／リスタート導線）をOK・キャンセルボタンで操作
9. タッチセンサーのキャリブレーション（起動時に初期値を記憶する仕組み。既存main.cppに実装済みの考え方を踏襲）
10. スタート画面（タイトルメニュー）: 「チュートリアル」「ゲーム開始」「設定」の3項目を十字キー（上下）で選択し、OKボタンで決定。あわせて十字キー（方向）・OK・キャンセル各ボタンの役割説明を画面内に表示する
11. チュートリアルモード: 自機の移動方法と、壁に当たるとゲームオーバーになることを実際に操作させながら学べるガイド画面
12. 設定モード: 十字キー（タッチ）の検出しきい値（＝移動感度）を3段階（弱・中・強 など）で調整できる設定画面
13. 難易度選択画面: 「ゲーム開始」選択後、レベル1〜3から難易度を選ぶ。難易度により自機サイズ（レベル1＝小〜レベル3＝大）と壁が狭くなる速度（レベル1＝遅い〜レベル3＝速い）が変化する

> 以下は今回のスコープ外（別途要望があれば追加検討）：
> - ベストスコア（最長生存時間）の永続保存（NVS/Preferences）
> - 音・LEDなどによる演出フィードバック

## 4. 成功の定義

- タッチセンサー4方向（上下左右）で自機を自在に微調整移動できる。
- 壁が右から出現し、時間経過とともに開口・出現間隔が狭くなりながら左へスクロールしてくる。
- 壁に触れたら失敗（ゲームオーバー）と判定され、その時点までの生存時間がスコアとして表示される。
- クリア（ゴール）は存在せず、どれだけ長く生き残れるかを競うゲームとして成立している。
- スタート画面から「チュートリアル」「ゲーム開始」「設定」を選択でき、初めてのプレイヤーでも迷わず本編に進める。
- スタート画面に十字キー・OK・キャンセルボタンの操作説明が表示され、説明書なしでも操作方法が分かる。
- チュートリアルで、自機の動かし方と壁に当たるとゲームオーバーになることを体験的に理解できる。
- 設定画面でタッチ値のしきい値（移動感度）を3段階から選び、実際のプレイ（方向判定）に反映できる。
- 「ゲーム開始」選択後にレベル1〜3の難易度を選べ、選んだレベルに応じて自機サイズと壁が狭くなる速度が変化する。
- 実機（AtomS3）上で一連の流れ（タイトル→（チュートリアル／設定／難易度選択）→プレイ→ゲームオーバー→リスタート）が安定して動作する。

## 5. ビジネス要件

個人の学習・趣味目的のプロジェクトであり、商用要件・収益化要件は設定しない。

## 6. ユーザーストーリー

- プレイヤーとして、電源を入れたらタイトル画面が表示され、「チュートリアル」「ゲーム開始」「設定」から選びたい。
- プレイヤーとして、タイトル画面を見ただけで十字キー・OK・キャンセルボタンそれぞれの役割が分かるようにしたい。
- 初めてのプレイヤーとして、チュートリアルで自機の動かし方と壁に当たるとゲームオーバーになることを実際に試しながら理解したい。
- プレイヤーとして、設定画面で自分の指の感覚に合ったタッチ値のしきい値（移動感度、3段階）を選びたい。
- プレイヤーとして、「ゲーム開始」を選んだら続けて難易度（レベル1〜3）を選び、自分の腕前に合った自機サイズ・難易度でプレイしたい。
- プレイヤーとして、十字キー（タッチ）で自機を上下左右に細かく動かして壁を避けたい。
- プレイヤーとして、壁に触れたら失敗（ゲームオーバー）したことがすぐに分かるようにしたい。
- プレイヤーとして、ゲームオーバー時に自分がどれだけ生き残れたか（生存時間）を確認したい。
- プレイヤーとして、時間が経つほど壁の隙間や間隔が狭くなっていく緊張感を味わいたい。
- プレイヤーとして、失敗してもOKボタンですぐにリトライしたい。
- プレイヤーとして、プレイ中や結果画面からキャンセルボタンでタイトル画面に戻りたい。

## 7. 受け入れ条件

- [ ] GPIO5〜8のタッチセンサーそれぞれが上下左右いずれかの方向入力として機能する
- [ ] 起動時にタッチセンサーの初期値（未接触状態の基準値）を記憶し、個体差・環境差を吸収する
- [ ] 電源ON後、タイトル画面に「チュートリアル」「ゲーム開始」「設定」の3項目が表示される
- [ ] タイトル画面で十字キー（上下）によりメニュー項目を選択でき、OKボタンで決定できる
- [ ] タイトル画面に、十字キー（方向入力）・OKボタン・キャンセルボタンの役割を示す操作説明が表示される
- [ ] 「チュートリアル」を選ぶと、自機の移動方法と壁接触＝ゲームオーバーを学べるガイド画面に遷移する
- [ ] 「設定」を選ぶと、タッチ値のしきい値（移動感度）を3段階（弱・中・強）から選択でき、選んだしきい値が方向判定にそのまま反映される
- [ ] 「ゲーム開始」を選ぶと、レベル1〜3の難易度選択画面に遷移する
- [ ] 選択した難易度レベルに応じて自機のサイズが変化する（レベル1が最小、レベル3が最大）
- [ ] 選択した難易度レベルに応じて壁が狭くなる速度が変化する（レベル1が最も遅く、レベル3が最も速い）
- [ ] GPIO39（OKボタン）でタイトル画面・難易度選択画面からの選択決定、およびゲームオーバー後のリスタートができる
- [ ] GPIO38（キャンセルボタン）でプレイ中・結果画面・チュートリアル・設定画面・難易度選択画面からタイトル画面に戻れる
- [ ] 自機は画面左側を基準位置として表示され、十字キー入力で上下左右に移動できる
- [ ] 壁が画面右端から出現し、左へ向かってスクロールする
- [ ] 壁の開口（縦方向の隙間）が、プレイ開始からの経過時間に応じて徐々に狭くなる
- [ ] 壁同士の出現間隔（横方向・頻度）が、プレイ開始からの経過時間に応じて徐々に狭くなる
- [ ] 自機が壁に接触したら「失敗（ゲームオーバー）」と判定される
- [ ] ゲームオーバー時点までの生存時間がスコアとして表示される
- [ ] ゲームオーバー後、OKボタンの操作で最初からやり直せる

## 8. 機能要件

- タッチ値の読み取り: `touchRead()`でGPIO5(G5)/6(G6)/7(G7)/8(G8)の4ピンを周期的に読み取る
- 方向判定: 起動時のキャリブレーション値から一定閾値以上の変化があったチャンネルを「入力あり」と判定する
- 自機移動: 入力ありと判定された方向に、画面左側を基準としたエリア内で自機座標を上下左右に更新する
- 物理ボタン読み取り: GPIO39（OK）・GPIO38（キャンセル）をデジタル入力として読み取り、チャタリング防止のためデバウンス処理を行う
- タイトルメニュー: 「チュートリアル」「ゲーム開始」「設定」の3項目を保持し、十字キー（上下）でカーソル移動、OKボタンで決定する
- タイトル画面操作説明表示: 十字キー（上下左右）・OKボタン・キャンセルボタンそれぞれの役割を示すテキスト/アイコンをタイトル画面内に表示する
- ボタン操作によるゲーム状態遷移: OKボタンでタイトルの選択決定、ゲームオーバー→リスタート。キャンセルボタンでプレイ中/結果画面/チュートリアル/設定画面→タイトルに戻る
- チュートリアル: 自機移動のデモ表示と、壁（サンプル）に接触した際にゲームオーバーになることを示すガイド演出を行う
- 設定: タッチ値のしきい値3段階（弱・中・強）を保持し、十字キーで選択・OKボタンで確定する。確定したしきい値を、方向判定（キャリブレーション値からの変化量判定）にそのまま使用する
- 難易度選択: レベル1〜3を保持し、十字キーで選択・OKボタンで確定する。確定したレベルに応じて自機サイズと、壁の開口・出現間隔が狭くなる速度（縮小レート）を決定する
- 自機サイズ制御: 選択された難易度レベルに応じて自機（当たり判定を含む）のサイズを変更する（レベル1が最小、レベル3が最大）
- 壁生成: 画面右端に、上下の壁と通り抜け用の開口（隙間）をセットで生成する
- 壁スクロール: 生成された壁を一定速度で右から左へ移動させ、画面左端を過ぎたら消去する
- 難易度制御（開口）: プレイ開始からの経過時間と選択難易度レベルに応じて、新規生成される壁の開口サイズを徐々に縮小する（下限値を設ける。レベルが高いほど縮小が速い）
- 難易度制御（出現間隔）: プレイ開始からの経過時間と選択難易度レベルに応じて、壁の出現間隔（生成周期）を徐々に短縮する（下限値を設ける。レベルが高いほど短縮が速い）
- 衝突判定: 自機と壁領域が重なったら失敗（ゲームオーバー）状態に遷移する
- タイマー: プレイ開始時刻からの経過時間をミリ秒単位で計測し、画面に秒単位で表示する（＝生存時間スコア）
- 画面描画: 128x128のAtomS3画面に壁・自機・生存時間を表示する
- 画面描画（タイトル/チュートリアル/設定）: 128x128の限られた表示領域でも視認しやすいメニュー・ガイド・設定項目のレイアウトで表示する

## 9. 非機能要件

- 対象ハードウェア: M5Stack AtomS3（ESP32-S3、画面128x128、タッチ対応GPIOはG5/G6/G7/G8）。外付け物理スイッチをGPIO39（OK）/GPIO38（キャンセル）に接続する
- 開発環境: PlatformIO（board=`m5stack-atoms3`, framework=`arduino`）、ライブラリはM5Unified / M5GFX
- 操作応答性: タッチ入力から自機移動までの遅延が体感できるほど大きくならないこと（ループ周期は既存コードの100ms程度を基準に、ゲームとして違和感のない範囲に調整する）
- 個体差対応: タッチセンサーの感度は個体・環境（湿度、静電気等）で変動するため、閾値は固定値決め打ちにせず調整しやすい構造にする
- リソース管理: 複数の壁オブジェクトを同時に保持・スクロールさせても、AtomS3のRAM・処理速度内で安定動作すること
- 難易度カーブ: 開口・出現間隔の縮小に下限値を設け、理不尽に避けられない状態にならないよう調整可能な構造にする
- 保守性: `GUI`クラスなど既存の責務分割（入力読み取り／ゲームロジック／描画）を維持・拡張する

## 10. 未決事項（次のドキュメントで検討）

- 壁（開口・出現間隔）の初期値、縮小速度、下限値の具体的な数値
- 壁のスクロール速度（固定か、経過時間で加速するか）
- 自機の可動範囲（画面左側のどのエリア内で上下左右に動けるか、境界値）
- 壁・自機の当たり判定の具体的な形状（矩形判定か、円判定か）
- 十字キー4入力の閾値・キャリブレーション方式の具体仕様
- 物理ボタン（GPIO38/39）の配線方式（内蔵プルアップ/プルダウンの利用有無、押下時がHIGHかLOWか）
- チュートリアルの具体的な進行内容・ステップ数（例: 「動かしてみよう」→「壁に当ててゲームオーバーを体験」の2ステップ等）
- タッチ値のしきい値3段階（弱・中・強）それぞれの具体的な数値
- 設定した移動感度を電源OFF後も保持するか（NVS/Preferencesへの保存）、それとも起動のたびにデフォルト値に戻るか
- 難易度レベル1〜3それぞれの、自機サイズの具体的な数値（半径・辺の長さ等）
- 難易度レベル1〜3それぞれの、壁の開口・出現間隔の初期値と縮小レートの具体的な数値
- 選択した難易度レベルを電源OFF後も保持するか、それとも起動のたびにデフォルト（例: レベル1）に戻るか
- タイトル画面の操作説明の具体的な表現方法（テキスト表記か、アイコン/ピクトグラムか）と、128x128の限られた画面内でのレイアウト
