# ユビキタス言語定義（glossary.md）

`docs/`配下の各ドキュメントおよびコード上で用いる用語を統一するための対応表。

## 1. ドメイン用語（ゲームの概念）

| 日本語 | 英語・コード上の識別子 | 定義 |
|---|---|---|
| イライラ棒 | Irairabou（プロダクト名としてはそのまま） | 本アプリの通称。ワイヤーに触れずに進む遊びから着想を得た、壁を避け続ける生存型ミニゲーム |
| 自機 | `Player` | プレイヤーが操作するキャラクター。画面左側を基準位置とし、十字キーで上下左右に移動する |
| 壁 | `Wall` | 画面右端から出現し左へスクロールする障害物。上下1組で1つの「開口」を形成する |
| 開口 | `gap` / `gapHeight` | 壁の中でプレイヤーが通り抜けられる縦方向の隙間 |
| 出現間隔 | `spawnInterval` | 壁同士が生成される横方向の間隔（頻度） |
| 生存時間 | `survivalTimeMs` | プレイ開始からゲームオーバーまでの経過時間。本アプリにおけるスコアそのもの |
| ゲームオーバー | `GameState::GAME_OVER` | 自機が壁に接触した状態。クリア（ゴール）は存在しない |
| 難易度レベル | `DifficultyLevel` (`level: 1〜3`) | 自機サイズと壁の縮小速度を決めるプリセット。レベル1が易しく、レベル3が難しい |
| しきい値（感度） | `SensitivitySetting` (`LOW`/`MID`/`HIGH`) | タッチセンサーの「入力あり」判定に使う変化量の基準値。設定画面で3段階から選べる |
| キャリブレーション | calibration | 起動時にタッチセンサーの未接触状態の基準値を記憶する処理 |

## 2. UI/UX用語（画面・操作）

| 日本語 | 英語・コード上の識別子 | 定義 |
|---|---|---|
| タイトル画面 | `GameState::TITLE` | 電源ON後に表示される、メニュー選択画面（チュートリアル/ゲーム開始/設定） |
| チュートリアル | `GameState::TUTORIAL` | 自機の動かし方と、壁接触＝ゲームオーバーを体験的に学ぶガイド画面 |
| 設定画面 | `GameState::SETTINGS` | しきい値（感度）を3段階から選ぶ画面 |
| 難易度選択画面 | `GameState::DIFFICULTY_SELECT` | ゲーム開始前にレベル1〜3を選ぶ画面 |
| プレイ中 | `GameState::PLAYING` | 壁を避け続ける本編プレイ画面 |
| 十字キー | D-pad（コード上は`InputManager`のタッチ4ch判定） | GPIO5〜8のタッチセンサーを上下左右の方向入力として扱う仮想的な十字キー |
| OKボタン | `ButtonInput::okPressed`（GPIO39） | メニュー決定・リスタートに使う物理ボタン |
| キャンセルボタン | `ButtonInput::cancelPressed`（GPIO38） | 各画面からタイトルに戻るのに使う物理ボタン |

## 3. コンポーネント名（コード上の命名規則）

| コンポーネント名 | 責務 |
|---|---|
| `InputManager` | タッチ4ch・ボタン2個の読み取りと判定 |
| `GameStateMachine` | `GameState`の保持と画面遷移の制御 |
| `SettingsStore` | しきい値（感度）設定の保持 |
| `DifficultyConfig` | 難易度レベルごとのパラメータテーブル |
| `Player` | 自機の座標・サイズ・移動 |
| `Wall` / `WallManager` | 壁1本分のデータ、および壁群の生成・スクロール・消去 |
| `CollisionChecker` | 自機と壁の当たり判定 |
| `GUI` | 画面描画（Renderer）。既存クラスを拡張 |

命名規則自体は`docs/development-guidelines.md`の「2. 命名規則」を正とする。

## 4. 用語の使い分けに関する注意

- 「クリア」という言葉は本アプリには存在しない（ゴールがなく、生存時間を競うゲームのため）。ドキュメント・コード・画面表示のいずれにおいても「クリア」ではなく「ゲームオーバー」「生存時間」を用いる
- 「感度」と「しきい値」は同一設定を指す（`docs/product-requirements.md`で用語を統一済み）。ドキュメント上は「タッチ値のしきい値（感度）」のように併記する
- 「失敗回数」「通算プレイ回数」は本アプリのスコープから除外済みの概念であり、今後のドキュメント・実装でも使用しない
